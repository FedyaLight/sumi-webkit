# Sumi 0.0.5 Alpha 5

Alpha 5 moves Sumi's release channel to a single Apple-silicon build, replaces prepared blocking bundles with locally built Adblock generations, and makes browser-owned storage cleanup safer and more bounded.

## Highlights

- One signed Arm64 DMG serves both direct installs and Sparkle updates. Alpha 4 is the final Intel-compatible build for installations that already have it; native Intel Macs are never offered an incompatible archive.
- Adblock now downloads the filter lists you choose and compiles one atomic native WebKit and advanced-blocking generation locally. Existing per-site overrides remain intact.
- Regular-profile storage lifecycle work adds a bounded HTTP disk-cache budget, safe reclamation of stale persistent website data and extension-controller storage, and a shared regular-profile favicon store while private windows remain isolated.
- Site permission decisions migrate to the regular install-wide scope so a browser-level decision is consistent across regular profiles.

## Browser and Storage Reliability

- Cache maintenance only deletes eligible regular-profile HTTP caches through the browser's destructive-cleanup admission path, and retries an interrupted upgrade instead of marking it complete.
- Stale website-data and extension-controller namespaces are reclaimed in bounded batches without touching live profile state.
- Older per-profile regular favicon caches migrate to the shared regular store; private favicon state stays separate.

## Adblock

- Removed the prepared protection-bundle workflow.
- Applying selected filters now builds a verified local generation for WebKit content blocking and advanced rules together.
- Retention removes inactive generations without disturbing the current selection or user site exceptions.

## Polish and Settings

- Settings reliably comes to the front when opened.
- Certificate warnings route and present through the active browser surface.
- Sidebar hover actions respond immediately, unloaded regular tabs no longer show an extra indicator dot, and Space title chevrons no longer overshoot.
- URL Hub popovers use the corrected presentation surface.

## Download and Updating

- `Sumi-0.0.5-build9-macos-arm64.dmg` — Apple-silicon Macs and Sparkle updates.
- Both historic Sparkle feeds point eligible Apple-silicon installations directly to Alpha 5.
- A native Intel Mac receives no Arm-only update. Alpha 4 is the final Intel-compatible build for installations that already have it.

## Installation Boundary

The app is development-signed, not Developer ID signed or notarized. If macOS says the app is damaged, move it to `/Applications` and remove the quarantine flag:

```sh
sudo xattr -dr com.apple.quarantine "/Applications/Sumi.app"
open "/Applications/Sumi.app"
```

Run this only for a Sumi bundle intentionally downloaded from the official GitHub Release.
