# Sumi 0.0.3 Alpha 3

Alpha 3 makes Sumi more reliable during everyday browsing, with substantial improvements to navigation, Glance, media playback, fullscreen, the sidebar, and Settings.

## Highlights

- Added automatic Glance for eligible links opened from Favorites and pinned tabs while preserving normal download, extension, modifier-click, middle-click, window, and same-frame behavior.
- Reworked the sidebar mini-player for multiple media sessions with focus, playback, mute, Picture in Picture, and dismissal controls.
- Reduced energy use during fullscreen video and improved native fullscreen and WebKit page-presentation lifecycles.
- Added configurable dimming and desaturation for unloaded tabs.
- Expanded Search Engine settings and unified native keyboard and menu command routing.
- Renamed Essentials to Favorites throughout Sumi.

## Navigation and Glance

- Fixed navigation inside Glance previews and teardown after closing or promoting previews.
- Fixed browser link-navigation fallbacks and kept automatic Glance behind the same popup admission and exact-document validation as ordinary browser surfaces.
- Improved the page-loading indicator and its integration with Glance.

## Sidebar, Tabs, and Folders

- Fixed Favorite selection across profiles, tab-close visual handoff hangs, and favicon update flicker.
- Improved collapsed-sidebar hover behavior, docked collapse animation, and vertical spacing.
- Fixed folder transition snapshots, folder-preview appearance changes, custom folder-icon selection, and cancelled split-picker cleanup.

## Settings, Extensions, and Reliability

- Added search-engine filtering, editing, removal, restoration, and Tab Search controls.
- Moved Keyboard settings search into the toolbar and exposed commands through one native routing path.
- Fixed duplicate extension context-menu items, media context-menu downloads, and accidental command-palette activation from middle-clicks.
- Hardened page runtime lifecycle management and improved notification secondary-text contrast.
- Renamed “What's new in Sumi” to “Changelog” in About Sumi.

## Downloads

- `Sumi-0.0.3-macos-arm64.dmg` — Apple silicon Macs.
- `Sumi-0.0.3-macos-x86_64.dmg` — Intel Macs.
- `Sumi-0.0.3-build5-macos-universal.dmg` — automatic updates for existing Apple silicon and Intel installations.

All three artifacts are built with the repository release configuration, signed with the project's configured Apple development account, mounted, architecture-checked, and code-signature-verified by the release tooling.

## Updating

Installed `0.0.2` builds receive Alpha 3 through Sumi's Alpha update feed. Installed `0.0.1` builds first receive the Alpha 2 bridge release and then join the same Alpha channel.

## Installation Boundary

The app is development-signed, not Developer ID signed or notarized. If macOS says the app is damaged, move it to `/Applications` and remove the quarantine flag:

```sh
sudo xattr -dr com.apple.quarantine "/Applications/Sumi.app"
open "/Applications/Sumi.app"
```

Run this only for a Sumi bundle intentionally downloaded from the official GitHub Release.
