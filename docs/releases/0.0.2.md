# Sumi 0.0.2 Alpha 2

Alpha 2 is the second public Sumi release. It remains early software and is not yet recommended as a primary browser.

## Highlights

- Rebuilt Settings as a dedicated native macOS window and reworked History and Bookmarks with native AppKit tables.
- Added native Picture in Picture controls to the sidebar media player.
- Added a native certificate warning flow with per-navigation trust decisions.
- Improved collapsed-sidebar interaction, automatic scrolling, hover restoration, space transitions, and favicon transitions.
- Improved Safari Web Extension discovery, installation, activation, removal, profile initialization, Glance support, pinning, reordering, and popup presentation.
- Moved background media and fullscreen behavior back to native WebKit handling.
- Fixed command-palette editing, Settings shortcuts, file-picker activation, restored launcher navigation, and Glance promotion flashes.
- Added a dedicated Alpha update channel, post-update sidebar notice, and clearer About Sumi update presentation.

## Download

- `Sumi-0.0.2-macos-arm64.dmg` — Apple silicon Macs.
- `Sumi-0.0.2-macos-x86_64.dmg` — Intel Macs.
- `Sumi-0.0.2-macos-universal.dmg` — automatic updates for existing Apple silicon and Intel installations.

All three artifacts are compiled independently, signed with the project's configured Apple development account, mounted, architecture-checked, and code-signature-verified by the repository release tooling.

## Updating from Alpha 1

Installed `0.0.1` builds receive Alpha 2 through their existing Sparkle feed. Alpha 2 moves the installation to Sumi's dedicated Alpha update feed for subsequent Alpha releases.

## Installation Boundary

The app is development-signed, not Developer ID signed or notarized. If macOS says the app is damaged, move it to `/Applications` and remove the quarantine flag:

```sh
sudo xattr -dr com.apple.quarantine "/Applications/Sumi.app"
open "/Applications/Sumi.app"
```

Run this only for a Sumi bundle intentionally downloaded from the official GitHub Release.
