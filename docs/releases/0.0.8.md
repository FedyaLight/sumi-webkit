# Sumi 0.0.8

This release fixes restored-tab fallback loading, makes History and Bookmarks navigation immediate, and removes an unwanted sidebar animation during launch.

## Highlights

- Opening a History or Bookmarks link in the current tab replaces the library page immediately instead of leaving it visible while the destination loads.
- A new General setting can open History and Bookmarks links in a new tab by default. Command-click continues to open a new tab regardless of the setting.
- Closing the active tab while a restored session is still starting loads the selected fallback tab automatically instead of leaving it cold until another click.
- Restored sidebar visibility snaps into place at launch instead of animating after the window appears, so the loading indicator no longer slides with it.

## Download and Updating

- `Sumi-0.0.8-build13-macos-arm64.dmg` is the single immutable artifact for direct installs and Sparkle updates.
- Both Sparkle feeds point eligible Apple-silicon installations to the same signed Arm64 item.
- The appcast hardware requirement is `arm64`. An older Sumi installation on an Apple-silicon Mac can update, including an Intel build running under Rosetta. Native Intel Macs receive no incompatible update.
- Historic Intel and Universal release assets remain available.

## Installation Boundary

The app is development-signed, not Developer ID signed or notarized. If macOS says the app is damaged, move it to `/Applications` and remove the quarantine flag:

```sh
sudo xattr -dr com.apple.quarantine "/Applications/Sumi.app"
open "/Applications/Sumi.app"
```

Run this only for a Sumi bundle intentionally downloaded from the official GitHub Release.
