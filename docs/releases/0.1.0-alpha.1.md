# Sumi 0.1.0 Alpha 1

This is Sumi's first public alpha: a native macOS browser built with SwiftUI, AppKit, and system WebKit.

## Download

- `Sumi-0.1.0-1-alpha-macos-arm64.dmg` — Apple silicon Macs.
- `Sumi-0.1.0-1-alpha-macos-x86_64.dmg` — Intel Macs.

Both artifacts are compiled independently, mounted, architecture-checked, and code-signature-verified by the repository release tooling. The Intel artifact has not yet had a manual pass on physical Intel hardware.

## Highlights

- Tabs, windows, profiles, spaces, pinned items, Essentials, nested folders, Glance, and durable two-to-four-page split groups.
- Command palette, bookmarks, history, downloads, Reader presentation, session restore, themes, media controls, and memory/energy modes.
- Browser import, Zen export, and logical Sumi backup/restore.
- Profile-specific WebKit data partitions, private browsing, permissions, cleanup, Global Privacy Control, and prepared content-blocking bundles.
- Experimental Safari Web Extension workflows tested with Bitwarden, Proton Pass, Raindrop.io, and Userscripts.
- Optional, off-by-default Live Folders and Boosts.

## Alpha Boundaries

- The app is development-signed, not Developer ID signed or notarized. macOS may require **System Settings → Privacy & Security → Open Anyway** for the first launch.
- Sumi is not yet recommended as a primary browser.
- Safari Web Extension compatibility is workflow-specific; 1Password's native-core path is limited by a host entitlement outside Safari.
- There is no Sumi-specific Apple Passwords/iCloud Keychain integration, and system AutoFill behavior has not completed release E2E validation.
- Backup v1 excludes passwords, cookies, WebKit website data, history, extension state, downloads, and preferences.
- The first appcast remains empty; updating from this build will be validated with a later alpha.
