# Sumi 0.0.4 Alpha 4

Alpha 4 improves redirect and external-app handoffs, keeps navigation feedback continuous, makes Sidebar Mini Player sessions more predictable, and prevents automatic history retention from signing users out of websites.

## Highlights

- OAuth and other external-app callbacks can complete from an active main-frame redirect after the original WebKit gesture has expired.
- The loading indicator remains continuous across short redirect and successor-navigation chains.
- Private-window pages are resolved from their window-local ephemeral session and appear in the compositor correctly.
- Sidebar Mini Player controls stay scoped to the exact page session and window that owns each card.
- Automatic retention removes expired history without deleting website data or sign-ins.

## Navigation and External Apps

- Limited automatic external-app attempts to one per page while keeping iframe, background, Glance, and other non-normal surfaces blocked.
- Hardened stored external-app permissions so they cannot be reused by subframes or auxiliary surfaces, even after a user interaction.
- Preserved the committed page across redirect settlement and presentation-URL changes so popup and page ownership remain attached to the document actually on screen.
- Recovered the exact current document when WebKit finishes a rewritten navigation without delivering its commit callback.

## Sidebar Mini Player

- Kept cards stable after pausing or muting from the Mini Player, without resuming media when the page is activated.
- Made dismissed cards stay dismissed until a new audible playback session starts.
- Rolled back failed or stale playback, mute, Picture in Picture, and dismissal commands cleanly.

## Privacy

- Automatic retention now deletes only browsing history older than the selected period. Website data and sign-ins are preserved.
- Manual website-data and cache clearing remain available from Data & Recovery.
- Private-window WebViews remain window-scoped and are now attached to their visible compositor correctly.

## Updating

Installed Alpha 2 and later builds receive Alpha 4 through Sumi's Alpha update feed. Installed `0.0.1` builds first receive the Alpha 2 bridge release and then join the same Alpha channel.

## Installation Boundary

The app is development-signed, not Developer ID signed or notarized. If macOS says the app is damaged, move it to `/Applications` and remove the quarantine flag:

```sh
sudo xattr -dr com.apple.quarantine "/Applications/Sumi.app"
open "/Applications/Sumi.app"
```

Run this only for a Sumi bundle intentionally downloaded from the official GitHub Release.
