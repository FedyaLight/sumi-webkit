# Sumi 0.0.9

This release makes Developer Tools open the active page inspector, restores navigated Favorites to the right address, and moves several browser storage paths off the main thread.

## Highlights

- The Developer Tools command and Command-Option-I open the docked Web Inspector for the active page, including a Glance preview, instead of showing instructions.
- A restored Favorite that had navigated away from its saved address loads its current page after startup and when selected as the fallback after closing another Favorite.
- Boost data loads without blocking the browser, applies to pages that are already open when loading finishes, and preserves edits made during the load.
- Session snapshots are written outside the main thread, and cached favicon reads no longer pull cold metadata from the database, reducing storage-related stalls during browsing.

## Download and Updating

- `Sumi-0.0.9-build14-macos-arm64.dmg` is the single immutable artifact for direct installs and Sparkle updates.
- Both Sparkle feeds point eligible Apple-silicon installations to the same signed Arm64 item.
- The appcast hardware requirement is `arm64`. An older Sumi installation on an Apple-silicon Mac can update, including an Intel build running under Rosetta. Native Intel Macs receive no incompatible update.
- Historic Intel and Universal release assets remain available.

## Installation Boundary

The app is development-signed, not Developer ID signed or notarized. If macOS says the app is damaged, move it to `/Applications` and remove the quarantine flag:

```sh
sudo xattr -dr com.apple.quarantine "/Applications/Sumi.app"
open "/Applications/Sumi.app"
```

Run this only for a Sumi bundle intentionally downloaded from the official GitHub Release.
