# Sumi 0.0.6

This release fixes downloads and webpage actions, makes sidebar selection and hover reliable, and keeps host-specific Adblock cosmetic rules off unrelated pages.

## Highlights

- Gmail attachments served from directory-style URLs now download correctly.
- Webpage context menus have working commands for linked-file downloads, image saving, image copying, and text-fragment links.
- Selected sidebar items scroll into view with the smallest necessary movement, while background opens leave the current viewport alone.
- Promoting a Glance preview into a tab preserves CSS hover and the correct pointing-hand cursor.
- Domain-scoped cosmetic rules run only on matching hosts through the advanced Adblock pipeline. Existing compiled generations migrate locally.
- Favicons prefer appropriately sized sources, avoid uneven scaling, and reuse the canonical cache across sidebar surfaces.

## Browsing and Interaction

- Dragging from the top of a webpage no longer moves the browser window, so text selection and other page interactions work there. Window dragging remains available from the sidebar control strip.
- Windows restored fully off-screen after a display change return to a visible screen.
- Collapsed-sidebar hover no longer leaves stale hover state on the webpage underneath transient browser chrome.
- Terminal WebKit key events no longer produce a system beep after Sumi handles them.
- Browser-owned loading and certificate-warning surfaces follow the active Space and effective light or dark appearance.

## Adblock and Favicons

- Generic and exclusion-based cosmetic rules remain in WebKit for first-paint blocking. Only host-specific selectors move to the per-host advanced pipeline.
- Installed Adblock generations migrate to the new cosmetic-domain artifact locally, without downloading a replacement generation or changing the selected filters and site exceptions.
- Initial favicon selection and later page updates use the same candidate ordering, so a stored favicon is not replaced by a differently ranked candidate.
- Near-target raster favicons use high-quality CPU resampling to keep diagonal edges even. Favorite backdrop blur work runs off the main thread.

## Download and Updating

- `Sumi-0.0.6-build10-macos-arm64.dmg` is the single immutable artifact for direct installs and Sparkle updates.
- Both Sparkle feeds point eligible Apple-silicon installations to the same signed Arm64 item.
- The appcast hardware requirement is `arm64`. An older Sumi installation on an Apple-silicon Mac can update, including an Intel build running under Rosetta. Native Intel Macs receive no incompatible update.
- Historic Intel and Universal release assets remain available.

## Installation Boundary

The app is development-signed, not Developer ID signed or notarized. If macOS says the app is damaged, move it to `/Applications` and remove the quarantine flag:

```sh
sudo xattr -dr com.apple.quarantine "/Applications/Sumi.app"
open "/Applications/Sumi.app"
```

Run this only for a Sumi bundle intentionally downloaded from the official GitHub Release.
